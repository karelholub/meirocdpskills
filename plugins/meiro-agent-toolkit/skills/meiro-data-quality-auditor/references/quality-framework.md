# Data quality framework

- Freshness: source activity, queue lag, model and attribute refresh recency.
- Completeness: expected event, identifier and attribute coverage by aggregate counts.
- Validity: type/cast failures and rejected destinations.
- Consistency: event-to-destination totals, dependencies and catalog joins.
- Uniqueness: identifier and deduplication design without raw identities.
- Reliability: error rate, retries, backlog and recovery.

Record window, baseline, numerator, denominator, filters and limitations for every metric.
