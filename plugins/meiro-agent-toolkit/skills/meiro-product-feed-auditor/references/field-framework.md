# Product feed field framework

- Identity: product ID, variant ID, parent/group ID, SKU.
- Merchandising: title, description, brand, taxonomy, tags.
- Commerce: regular price, sale price, currency, availability, quantity.
- Experience: canonical URL, image URL, locale, market.
- Governance: source owner, refresh timestamp, deletion/tombstone semantics.

Required fields depend on the use case. Recommendations normally need stable IDs, title, URL, usable image, price/currency, availability and taxonomy.
